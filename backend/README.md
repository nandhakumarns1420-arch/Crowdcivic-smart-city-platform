# CrowdCivic

CrowdCivic is a Smart City Civic Issue Reporting Platform that enables citizens to report civic issues while allowing administrators to monitor and resolve complaints efficiently.

## Features

- Citizen Registration/Login
- JWT Authentication
- Report Civic Issues
- Upload Images
- Complaint Tracking
- Duplicate Complaint Detection
- Admin Dashboard
- Complaint Analytics
- Notifications
- Cloudinary Image Storage
- MongoDB Database

## Tech Stack

Frontend

- React
- Vite
- Tailwind CSS
- React Router

Backend

- Node.js
- Express.js
- MongoDB Atlas
- JWT
- Cloudinary
